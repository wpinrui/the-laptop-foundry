# Brand decal sources

Real brand logos offered as player presets, used with the owner's go-ahead in a private repo. Each was fetched from Wikimedia Commons as SVG and flattened into a single one-ink evenodd path, 100 units tall. The ink colours live in `builder/decals.tsx`.

- `n1-nokia.svg`: https://commons.wikimedia.org/wiki/File:Nokia_wordmark.svg
- `n2-nokia-2023.svg`: https://commons.wikimedia.org/wiki/File:Nokia_2023.svg
- `n3-nokia-connecting-people.svg`: https://commons.wikimedia.org/wiki/File:Nokia_-_2005_logo.svg
- `m1-motorola-batwing.svg`: https://commons.wikimedia.org/wiki/File:Motorola_M_symbol_black.svg (the M alone)
- `m2-motorola-badge.svg`: https://commons.wikimedia.org/wiki/File:Motorola_M_symbol_black.svg (M knocked out of the disc)
- `m3-motorola.svg`: https://commons.wikimedia.org/wiki/File:Motorola-Logo.svg (wordmark only)
- `m4-motorola-lockup.svg`: https://commons.wikimedia.org/wiki/File:Motorola-Logo.svg
